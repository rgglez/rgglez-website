## Introduction

Lors de la préparation des images OpenGraph et FavIcon de ce blog de confiance, j'ai eu besoin de convertir un PNG en ICO. Sous Linux, c'est très facile à faire avec <a href="https://imagemagick.org/#gsc.tab=0" target="_blank">ImageMagick</a>.

## Étapes

Installer ImageMagick :

```bash
sudo apt install imagemagick
```

Convertir le PNG ou JPEG (256x256px) en ICO :

```bash
convert input.png -define icon:auto-resize=256,64,48,32,16 favicon.ico
```

Où :

* `-define icon:auto-resize=256,64,48,32,16` enregistre plusieurs icônes de ces tailles dans le fichier `.ico`.

Et voilà, c'est tout.
