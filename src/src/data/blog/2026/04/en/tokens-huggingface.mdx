## Introduction

According to Wikipedia:

> Hugging Face, Inc. is a French-American company that develops tools for
> building applications using machine learning. It is known for its
> Transformers library built for natural language processing applications,
> and its platform that allows users to share datasets and machine learning
> models.

## Step by Step

1. Go to <a href="https://huggingface.co" target="_blank">`huggingface.co`</a> and sign in to your account. If you do not have one, sign up.
1. Go to *Settings*:
    ![Image of the settings page](../../../../../assets/posts/2026/04/tokens-huggingface/step1.png)
1. In the side menu, select "*Access Tokens*":
    ![Image of the access tokens page](../../../../../assets/posts/2026/04/tokens-huggingface/step2.png)
1. Click "*Create new token*":
    ![Image of the new token page](../../../../../assets/posts/2026/04/tokens-huggingface/step3.png)
1. Give it a name, select type "`Write`" (required for uploading datasets) or "`Read`" (read-only). You can also create a *Fine grained* token with specific permissions, but for most use cases this is not necessary.
1. Click "*Generate a token*" and copy it.

<Aside type="caution">

the token **is shown only once**.

</Aside>

<Aside type="note">

the `HF_TOKEN` environment variable can be exported with the generated token value. If you need to use a different token, simply change the export:
```bash
export HF_TOKEN=my_token
```

</Aside>

## Useful CLI Commands

* `hf auth login` logs in to HuggingFace.
* `hf auth list` lists authorized tokens.
* `hf auth whoami` shows which user is currently logged in.

<Aside type="note">

some guides online state that the CLI command is `huggingface-cli`, which appears to be outdated.

</Aside>

## Bonus

The `HF_DEBUG` variable set to `1` can be used to debug interactions with HuggingFace.
