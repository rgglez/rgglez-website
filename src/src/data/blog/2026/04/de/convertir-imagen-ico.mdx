## Einführung

Während ich die OpenGraph- und FavIcon-Bilder für diesen, Ihren vertrauenswürdigen Blog, vorbereitete, musste ich ein PNG in ICO konvertieren. Unter Linux ist das mit <a href="https://imagemagick.org/#gsc.tab=0" target="_blank">ImageMagick</a> sehr einfach.

## Schritte

ImageMagick installieren:

```bash
sudo apt install imagemagick
```

Das PNG oder JPEG (256x256px) in ICO konvertieren:

```bash
convert input.png -define icon:auto-resize=256,64,48,32,16 favicon.ico
```

Wobei:

* `-define icon:auto-resize=256,64,48,32,16` mehrere Icons dieser Größen in der `.ico`-Datei speichert.

Und das war's.
